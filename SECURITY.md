# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within OpenPassport, please **do not** open a public issue.

Instead, please report security vulnerabilities directly to:
* **Email:** `moshequantum@gmail.com`
* Or submit a confidential advisory via **GitHub Security Advisories**.

Please include:
1. Detailed description of the vulnerability.
2. Steps or reproduction script / payload.
3. Potential impact and affected components.

We will acknowledge receipt within 48 hours and work with you on a responsible disclosure timeline.
